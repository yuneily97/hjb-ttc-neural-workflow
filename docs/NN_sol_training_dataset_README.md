# NN_sol_training_dataset.py

Trajectory dataset generation script.

Objective:
    Generate simulated trajectories under the proposed dynamics and save the training dataset used by the neural trajectory models.

Required before running:
    outputs_hjb_k1_nosup/value_net.keras generated by HBJ_train.py.

Main outputs:
    proposed_data_long_full.npz

Run order:
    Run after HBJ_train.py and before NN_V.py and NN_X.py.

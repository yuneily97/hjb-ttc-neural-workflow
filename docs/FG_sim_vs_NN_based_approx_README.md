# FG_sim_vs_NN_based_approx.py

Full simulation versus two-step neural approximation comparison script.

Objective:
    Compare the full ground-truth simulation with the two-step neural approximation that uses the first-stage [X,V] model and the second-stage X-only model.

Required before running:
    outputs_hjb_k1_nosup/value_net.keras generated by HBJ_train.py.
    trained_proposed_model_semi_supervised3_full_gt_sine_uniform_concent_on_close_just_leaky_relu_in_front_omega15_4_full.h5 generated by NN_V.py.
    trained_proposed_model_semi_supervised3_full_gt_sine_uniform_concent_on_close_just_leaky_relu_in_front_part2_omega15_4_full.h5 generated by NN_X.py.

Main outputs:
    NN_sol_vs_NN_based_approx/*.png

Run order:
    Run after NN_X.py. This script is an evaluation/figure-generation step.

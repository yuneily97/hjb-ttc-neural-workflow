# FG_sim_vs_NN_sim.py

Full simulation versus HJB-TTC neural simulation comparison script.

Objective:
    Compare the full ground-truth simulation using numerical TTC with a simulation that uses the trained HJB/value network as the TTC estimator.

Required before running:
    outputs_hjb_k1_nosup/value_net.keras generated by HBJ_train.py.

Main outputs:
    NN_sol_vs_NN_sim/phase_portrait_fg_vs_neunum.png

Run order:
    Run after HBJ_train.py. This script is an evaluation/figure-generation step.

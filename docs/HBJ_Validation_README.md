# HBJ_Validation.py

HJB value-network validation script.

Objective:
    Load the trained HJB/value network and compare its TTC/value predictions against ODE-based ground truth over admissible state grids.

Required before running:
    outputs_hjb_k1_nosup/value_net.keras generated by HBJ_train.py.

Main outputs:
    outputs_hjb_k1_nosup/validation_admissible/raw_admissible_results.csv
    outputs_hjb_k1_nosup/validation_admissible/admissible_2d_plot_mean.png

Run order:
    Run after HBJ_train.py. This step is diagnostic/validation and does not train later models.

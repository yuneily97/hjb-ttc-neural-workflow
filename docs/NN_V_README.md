# NN_V.py

First-stage trajectory neural-network training script.

Objective:
    Train the first-stage neural model that predicts both spacing X(t) and relative velocity V(t) from initial conditions, TTC/value features, and time.

Required before running:
    outputs_hjb_k1_nosup/value_net.keras generated by HBJ_train.py.
    proposed_data_long_full.npz generated by NN_sol_training_dataset.py.

Main outputs:
    trained_proposed_model_semi_supervised3_full_gt_sine_uniform_concent_on_close_just_leaky_relu_in_front_omega15_4_full.h5
    training_history_NN_V_gt_omega15_4_full.csv
    NN_V_output/*.png

Run order:
    Run after NN_sol_training_dataset.py and before NN_X.py.

# NN_X.py

Second-stage spacing-only neural-network training script.

Objective:
    Train the second-stage neural model that predicts spacing X(t), while using the pretrained first-stage model as the velocity provider in the loss.

Required before running:
    outputs_hjb_k1_nosup/value_net.keras generated by HBJ_train.py.
    proposed_data_long_full.npz generated by NN_sol_training_dataset.py.
    trained_proposed_model_semi_supervised3_full_gt_sine_uniform_concent_on_close_just_leaky_relu_in_front_omega15_4_full.h5 generated by NN_V.py.

Main outputs:
    trained_proposed_model_semi_supervised3_full_gt_sine_uniform_concent_on_close_just_leaky_relu_in_front_part2_omega15_4_full.h5
    training_history_NN_X_g_t_omega15_4_full.csv
    NN_X_output/*.png

Run order:
    Run after NN_V.py.

# NN_sol_nonlinear_stability.py

Nonlinear stability simulation script.

Objective:
    Simulate a multi-vehicle nonlinear traffic system using the trained HJB/value network and the trained neural trajectory models, then save stability-related profiles and figures.

Required before running:
    outputs_hjb_k1_nosup/value_net.keras generated by HBJ_train.py.
    trained_proposed_model_semi_supervised3_full_gt_sine_uniform_concent_on_close_just_leaky_relu_in_front_omega15_4_full.h5 generated by NN_V.py.
    trained_proposed_model_semi_supervised3_full_gt_sine_uniform_concent_on_close_just_leaky_relu_in_front_part2_omega15_4_full.h5 generated by NN_X.py.

Main outputs:
    sim_outputs/*.png
    stability_profiles/x_profiles_full_real4_sim3_full.npy
    stability_profiles/v_profiles_full_real4_sim3_full.npy
    stability_profiles/profiles_full_real4_sim3_full.npz

Run order:
    Run after NN_X.py. This script is a downstream stability simulation/evaluation step.

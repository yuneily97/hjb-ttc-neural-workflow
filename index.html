Cleaned Traffic Safety / HJB-TTC Neural Workflow

This repository contains cleaned Python scripts for the HJB/value-network TTC estimator and the two-stage neural trajectory workflow. The code is preserved for research reproduction, with concise documentation and a recommended execution sequence.

Python TensorFlow/Keras Traffic safety HJB/TTC Neural trajectory models

Setup

Create and activate a Python environment, then install the dependencies:

pip install -r requirements.txt

The scripts save and load .keras and .h5 model files. SciPy is pinned below 1.14 because several scripts use scipy.integrate.cumtrapz.

Minimum training pipeline

python HBJ_train.py
python NN_sol_training_dataset.py
python NN_V.py
python NN_X.py

Full recommended run sequence

python HBJ_train.py
python HBJ_Validation.py
python NN_sol_training_dataset.py
python NN_V.py
python NN_X.py
python FG_sim_vs_NN_sim.py
python FG_sim_vs_NN_based_approx.py
python NN_sol_nonlinear_stability.py
